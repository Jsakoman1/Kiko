# Kiko Project Brief

## Goal

Build a small AI context notebook while learning Python, program logic,
software architecture, and the foundations of safe AI-model integration.

## Learner profile

- Level: Beginner
- Language being learned: Python
- Previous experience: Java
- Explanation language: English

## Version 0.1

Kiko v0.1 is a command-line program that stores one mission, its rules, and
useful notes in a local JSON file.

### Required behavior

- Display command help.
- Create or replace one mission.
- Add permanent rules.
- Add context notes.
- Display the complete context.
- Preserve context between program runs.

### Not included

- Tasks, priorities, or dependencies
- Multiple missions or users
- Databases, web servers, or graphical interfaces
- AI API calls, MCP, embeddings, or semantic search
- External Python packages

## Constraints

- The learner writes all application source code.
- Use the Python standard library only.
- Keep the command-line architecture small and explicit.
- Introduce one coherent behavior per learning checkpoint.
- Teach deterministic application logic before connecting an AI model.
